网 站 部 署 开 发

从静态 HTML/CSS/JS 到 Netlify / Vercel 部署，独立搭建并上线个人站点与小游戏。

造物实验 持续迭代

项目概述 Overview

这是一个关于独立网站部署的项目——从前端的 HTML/CSS/JS 写起，到使用静态站点托管服务（Netlify / Vercel / Cloudflare Pages）一键部署上线，让作品真正能在互联网上被访问。本项目是这个个人简历站点本身，以及几个独立小游戏的部署实践。

技术栈 Stack

  • HTML5 / CSS3：语义化结构、CSS 变量、动画、响应式布局
  • 原生 JavaScript：DOM 操作、事件监听、localStorage / sessionStorage 持久化
  • Canvas 2D：2D 游戏渲染、绘图、像素操作
  • 静态部署：Netlify / Vercel / Cloudflare Pages 一键发布
  • 版本控制：Git + GitHub 仓库管理
