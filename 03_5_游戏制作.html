造物实验 持续迭代

项目概述 Overview

这是一个关于游戏制作的项目——独立完成从游戏策划、玩法设计、Canvas 渲染、碰撞检测、关卡系统、得分系统到 Netlify 部署上线的全流程。目前已上线两款游戏：星际战机（横版射击）与坦克大战（俯视策略对战）。点击下方卡片即可在线体验。

技术栈 Stack

  • 渲染：Canvas 2D API / requestAnimationFrame 主循环
  • 逻辑：原生 JavaScript ES6+ / 面向对象封装
  • 输入：键盘事件 + 触屏适配（支持移动端虚拟按键）
  • 系统：碰撞检测 / 关卡难度递增 / 得分排行（localStorage）
  • 部署：Netlify 静态托管 / GitHub 仓库版本管理
